## Contract Verification

- New Objectives receive one manager-generated opaque string ID.
- Tests can inject deterministic ID generators.
- Objective identity rejects reassignment to a different value.
- Canonical ID lookup is explicit and never inferred from goal strings.
- Latest-by-goal lookup remains compatible with existing callers.
- Complete-record iteration and persistence retain equal-goal Objectives.
- Identified records reload under their persisted IDs without generation.
- Legacy missing-ID records reload and save without synthesized identity.
- Duplicate non-null IDs fail closed during registration and persistence load.
